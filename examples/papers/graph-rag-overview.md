# 과학 QA를 위한 근거 기반 GraphRAG

## 초록

- 주장: 근거 기반 GraphRAG는 주장을 원문 구절과 연결해 과학 QA에서 근거 없는 답변을 줄인다.
- 개념: GraphRAG
- 개념: 근거 그래프

## 방법

- 방법: 추출된 주장, 방법, 실험, 한계를 바탕으로 GraphRAG 근거 그래프를 구성한다.
- 실험: 30개 질문으로 구성된 내부 벤치마크에서 그래프 기반 답변과 단순 검색 기반 답변을 비교했다.
- 결과: 그래프 기반 답변은 30개 벤치마크 질문 중 27개에서 원문 근거가 붙은 인용을 유지했다.

## 한계

- 한계: 벤치마크 규모가 작고 아직 서로 충돌하는 논문을 다루지 않는다.
