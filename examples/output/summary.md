# PaperGraph 요약

## 질문

GraphRAG는 과학 QA의 환각을 어떻게 줄이는가?

## 과학 QA를 위한 근거 기반 GraphRAG

논문 ID: `graph-rag-overview`

### 주장
- 근거 기반 GraphRAG는 주장을 원문 구절과 연결해 과학 QA에서 근거 없는 답변을 줄인다.

### 방법
- 추출된 주장, 방법, 실험, 한계를 바탕으로 GraphRAG 근거 그래프를 구성한다.

### 실험/결과
- 30개 질문으로 구성된 내부 벤치마크에서 그래프 기반 답변과 단순 검색 기반 답변을 비교했다.
- 그래프 기반 답변은 30개 벤치마크 질문 중 27개에서 원문 근거가 붙은 인용을 유지했다.

### 한계
- 벤치마크 규모가 작고 아직 서로 충돌하는 논문을 다루지 않는다.

### 개념
- GraphRAG
- 근거 그래프

## 문헌 QA 시스템의 실패 양상

논문 ID: `scientific-qa-limitations`

### 주장
- 문헌 QA 시스템은 정확한 근거 구절을 드러내지 않은 채 논문 묶음을 요약할 때 가장 눈에 띄게 실패한다.

### 방법
- 5개 논문에 대해 수동 근거 매트릭스를 만들고 각 주장을 원문 구절과 대조한다.

### 실험/결과
- 검토자는 생성 답변에서 근거 없는 요약과 누락된 한계를 표시했다.
- 근거 매트릭스 검토는 최종 종합문을 쓰기 전에 근거 없는 주장을 더 쉽게 걸러내게 했다.

### 한계
- 수동 검토는 넓은 의미 검색보다 느리며 더 나은 내보내기 도구가 필요하다.

### 개념
- 문헌 QA
- 근거 구절
